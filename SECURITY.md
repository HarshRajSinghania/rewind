# Security policy

Rewind keeps photos, face measurements and settings on the device, and album locks guard
private albums, so security issues matter even without a server.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/Wavefire5201/rewind/security/advisories/new),
not in a public issue. Include what's affected, how to reproduce it, and the impact you expect.

You'll get an acknowledgement within a few days, and a fix or a plan once the report is
confirmed. Only the latest release is supported.

Examples of what's in scope: bypassing an album lock, leaking photos or face data off the
device or to other apps, and unsafe handling of imported backup files.
