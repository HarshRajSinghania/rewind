# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and take feedback gracefully,
and focus on what's best for the project and its users. Harassment, insults, and personal or
political attacks aren't acceptable in issues, pull requests, or any other project space.

To report behavior that breaks these standards, open a
[private security advisory](https://github.com/Wavefire5201/rewind/security/advisories/new)
(it reaches the maintainer privately) or contact the maintainer through their GitHub profile.
Reports are handled confidentially.
